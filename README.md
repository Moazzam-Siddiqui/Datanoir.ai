How to run the programme locally:

Step 1:
Clone the repository

      git clone https://github.com/Moazzam-Siddiqui/Datanoir.ai/

Step 2: Make Sure all the files are in the same folder

Step 3:
Now open the code in your code editor and within your CMD terminal write

        python app.py

Step 4:
Just click your local host links and boom
